; PRELAB QUESTION 9

; Syntax:
; 1. Semicolon's are comments, anything after a Semicolon 
;    will be ignored during compilation
; 2. All instructions start with an instruction name, in
;    all caps. We currently support the following instructions:
;    BR,BRZ,ADDI,SUBI,SR0,SRH0,CLR,MOV,MOVA,MOVR,MOVRHS,PAUSE
; 3. Immediate constants are preceded by a pound, #
; 4. Register adresses are preceded by the letter r
; 5. Instruction parameters can be separated by a space, comma
;    or both. The compiler is not that fussy
; 6. Only one instruction is allowed per line

; Write an assembly level program that spins the motor three steps clockwise, 
; then moves it four half-steps counter-clockwise. 
; The delay between the steps should be 1/2 of a second. The programshould repeat these movements forever

; Let's see some code

CLR r0      
SR0 #2      
SRH0 #3     ; r0 = 50
MOV r3,r0   ; delay 50/100s of a second 
SR0 #1      ; r0 = 1
MOV r1 r0   ; 1 => r1 
CLR r0      ; setup loop counter
SR0 #3      ; r0 = 3
MOVR r1     ; move 1 full step CW
PAUSE
SUBI r0 #1  ; r0-1
BRZ #3		     ; branch 3 forwards 
BR #-4	     ; branch 4 backwards 
BR #-9
SR0 #15      ; r0 = -1
MOV r1 r0   ; -1 => r1
CLR r0      ; setup loop counter
SR0 #4      ; r0 = 4
MOVRHS r1   ; move 1 half step CCW
PAUSE
SUBI r0 #1  ; r0 -1
BR #2		     
BR #-4	           
BR #-10
