; PRELAB QUESTION 7

; Syntax:
; 1. Semicolon's are comments, anything after a Semicolon 
;    will be ignored during compilation
; 2. All instructions start with an instruction name, in
;    all caps. We currently support the following instructions:
;    BR,BRZ,ADDI,SUBI,SR0,SRH0,CLR,MOV,MOVA,MOVR,MOVRHS,PAUSE
; 3. Immediate constants are preceded by a pound, #
; 4. Register adresses are preceded by the letter r
; 5. Instruction parameters can be separated by a space, comma
;    or both. The compiler is not that fussy
; 6. Only one instruction is allowed per line

; Write an assembly-level program that puts the number consisting of the last two digits of your student (53)
; number into register R1, then adds 5 to this number and moves the result into register R0. Keep in
; mind that your student number is a decimal number, so take care to convert it into binary correc

; Let's see some code

CLR r0          ; clear Register 0 on start
CLR r1          ; clear Register 1 on start

SR0 #5          ; Set lower half of Register 0 to b0101
SRH0 #3         ; Set upper half of Register 0 to b0011

MOV r1 r0   ; move register 0 to register 1

ADDI r1 #2      ; Add 2 to Register 1
ADDI r1 #3      ; Add 3 to Register 1

MOV r0 r1       ; Move the Register 1 to Register 0

; To Compile Me:
; python3 compiler.py prelab7.txt
